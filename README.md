# 📘 Pokédex Web App

An interactive Pokédex web application that dynamically loads Pokémon data from an API and displays it in a modern, responsive user interface with search, detail view, and type-based styling.

🌐 **Live Demo:**  
https://davideisenbarth.infinityfreeapp.com/assets/projects/pokedex/index.html?i=1

---

## 🚀 Features

- 🔎 Live search for Pokémon
- 📋 Dynamically rendered Pokémon list
- ➕ "More Pokémon" button (Lazy Loading / Pagination)
- 🪟 Detail modal with stats and information
- 🎨 Type-based colors and dynamic styling
- ⏳ Loading animation (Pokéball Loader)
- ⚡ API-based data fetching
- 📱 Responsive design (Desktop & Mobile)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API
- REST API (Pokémon data)

---

## 🧠 Project Purpose

This project was built to practice and improve:

- API integration
- Asynchronous JavaScript
- Dynamic DOM manipulation
- UI structure and component thinking
- Responsive web design
- Performance optimization through lazy loading
